### 🏋️ Flagship: Training Log &nbsp;·&nbsp; 🚧 V1 in progress

**A mobile-first app to follow a weekly training routine, log sets fast at the gym, and review progress.**

![Next.js](https://img.shields.io/badge/Next.js-000000?style=flat-square&logo=next.js&logoColor=white) ![TypeScript](https://img.shields.io/badge/TypeScript-3178C6?style=flat-square&logo=typescript&logoColor=white) ![Drizzle](https://img.shields.io/badge/Drizzle_ORM-C5F74F?style=flat-square&logo=drizzle&logoColor=black) ![PostgreSQL](https://img.shields.io/badge/PostgreSQL-4169E1?style=flat-square&logo=postgresql&logoColor=white) ![Neon](https://img.shields.io/badge/Neon-00E599?style=flat-square&logo=neon&logoColor=black) ![Better Auth](https://img.shields.io/badge/Better_Auth-000000?style=flat-square&logo=betterauth&logoColor=white) ![Vercel](https://img.shields.io/badge/Vercel-000000?style=flat-square&logo=vercel&logoColor=white)

- **Derived, not stored:** a Week's Sessions and their status (Pending, Completed, Missed) are computed from the Schedule history, moves and Set logs, so no stored status can drift and nothing is written on read.
- **Pure domain module:** training rules take today as an input and import nothing from Next.js, Drizzle or the clock, so they run as fast unit tests. Use cases are tested against real Postgres.
- **Per-visitor demo users:** each "Try the demo" visitor gets their own anonymous user with deterministic seeded history, which is removed after a day. The owner's data stays private.
- **Spec-first with coding agents:** a shared glossary, ADRs, GitHub Issues as specs and agent skills drive every slice.
